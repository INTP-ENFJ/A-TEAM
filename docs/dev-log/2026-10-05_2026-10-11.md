   - **개발자용 설명 / 원인**: 제목 영역(`mb-6 pb-6 border-b border-slate-100`) 직하단에 위치한 바이라인 띠(`bg-slate-50 border-y border-slate-200 py-2.5 px-3 mb-8`)가 캔버스 내부 패딩 안쪽에 좌우가 뚝 끊긴 사각형 박스로 갇혀 있고, 하단 마진(`mb-8`)이 본문 섹션 간격(`space-y-6`)과 불일치하여 제목부와 본문이 분리되어 보임.
   - **발생 시점**: 2-1 렌더링 분석 단계
3. **오류 3: TypeScript 중복 속성 컴파일 오류**
   - **오류 메시지**: `error TS2783: 'type' is specified more than once, so this usage will be overwritten.`
   - **개발자용 설명**: `MediaItem` 객체 자체에 `type: 'image' | 'video'` 필드가 존재하는데 `{ type: 'media-library-item', ...item }` 형태로 객체를 스프레드하여 TS2783 에러 발생.
   - **일반인 설명**: 미디어 정보를 전달하는 데이터 구조에서 '종류(type)'라는 속성 이름이 중복 선언되어 빌드가 실패함.
   - **발생 시점**: `npm run lint` 검증 단계

### 원인
- 미디어 라이브러리와 내부 블록이 동일한 `application/json` 데이터 채널을 경쟁적으로 사용하여 잘못된 역직렬화 흐름 발생.

### 해결 방법
1. `MediaLibraryDrawer.tsx`에서 `const { type: mediaType, ...restItem } = item;` 구조 분해를 적용하여 TS2783을 방지하고 `application/x-press-cms-media` 단일 채널로 `type: 'media-library-item'`, `mediaType`을 안전하게 전송.
