## 주간 DEV_LOG 운영 규칙

1. **주간 단위 파일 관리**: 월요일 00:00 ~ 일요일 23:59 기준으로 `YYYY-MM-DD_YYYY-MM-DD.md` 파일을 생성/관리합니다.
2. **작업 시작 시 확인**:
   - 현재 날짜가 속한 주간 DEV_LOG 파일 확인
   - 없으면 새 주간 파일 생성 후 INDEX 표에 등록
   - 있으면 기존 파일의 해당 날짜 아래에 작업 기록 추가
3. **불변성 및 투명성**:
   - 주가 바뀌면 이전 주 파일을 수정하지 않고 새 주간 파일을 생성합니다.
   - 단, 이전 기록의 사실 오류를 정정할 경우 수정 사유를 명시하고 수정합니다.
   - 실제 검증된 사실만 기록하며, 실패한 시도와 Root Cause도 보존합니다.
4. **보안 준수**: 비밀번호, 토큰, API Key, service_role, activationLink 등 비밀정보는 절대 기록하지 않습니다.
